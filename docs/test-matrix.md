# Public Test Matrix

This matrix summarizes the automated test coverage for Parametron Engine across
its core architectural layers.

| Area | Coverage | Primary Validation Command | Notes |
|:-----|:---------|:---------------------------|:------|

## Integration and End-to-End Proof

| Boundary | Coverage | Validation Command | Notes |
|:---------|:---------|:-------------------|:------|
| **Controlled Simulation Proof** | End-to-end multi-attempt retry, timeout handling, verification failure, cancellation, and API execution | `python scripts/cad_runtime_integration_proof.py --mode fake` | Uses deterministic mock CAD runtime; no external FreeCAD required |
| **Engine-owned FreeCAD Runtime Contract Package** | Permanent normal CLI proof from project and DSL target actions through planning, scheduling, executor handoff, isolated attempt preparation, the actual external `runtimecap` process boundary, evidence intake, Engine verification, outcome consumption, and normal record-package emission | `go test ./cmd/parametron/... -run 'TestContractPackage_'` | Uses a repository-controlled external runtime participant, not real FreeCAD. Covers ordinary execution; `suppress`, `unsuppress`, `hide`, `unhide`, and `delete`; Part/Assembly destinations; combined mutation families; schema `1.0` content across the manifest, verification request, traversal request, result, observed output, and returned traversal evidence; deterministic ordering and request materialization; staged-source and attempt-path containment; observation independence from requested intent; suppression, visibility, and deletion mismatches; omitted required evidence; unavailable native evidence; missing targets; malformed evidence rejection before semantic verification; and runtime-native failure separation. Eligible traversal evidence produces a normalized reference record with exact raw-byte provenance. Successful runs emit applicable execution, artifact, observation, and verification records while preserving raw result, verification-request, and observed evidence separately. Equivalent runs prove stable plan, job, and attempt identities, canonical runtime manifests, equivalent-location observation requests, semantic verification results, normalized records, and package entry ordering and identities; runtime-produced operational evidence is not claimed byte-identical. This proof covers the normal CLI path and does not cover HTTP API target-mutation submission or real FreeCAD-native mutation and observation. |
| **Opt-in FreeCAD Integration** | Live CAD document mutation, recompute, STEP export, Engine verification, and repeated execution using `parametron-freecad` | `PARAMETRON_RUN_FREECAD_INTEGRATION=1 python scripts/cad_runtime_integration_proof.py --mode real --freecad-repo ../parametron-freecad` | Requires the sibling FreeCAD runtime to accept the canonical schema 1.0 traversal request and emit schema 1.0 traversal evidence; the current unmodified FreeCAD revision still implements the prior traversal generation. |
| **Opt-in FreeCAD Adapter Unit Tests** | FreeCAD adapter smoke tests against local `freecadcmd` binary | `PARAMETRON_RUN_FREECAD_INTEGRATION=1 PARAMETRON_FREECAD_BIN=/path/to/freecadcmd go test ./internal/engine/adapter/freecad/...` | Opt-in smoke validation |

## Comprehensive Test Execution

```bash
# Run all unit and package tests
go test ./...

# Run static analysis
go vet ./...

# Run race detector across concurrent subsystems
go test -race ./internal/engine/cache/... ./internal/engine/api/... ./internal/engine/scheduler/...
```
